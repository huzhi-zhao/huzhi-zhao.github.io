# ADR-0011 About 页的职责边界：只做人味，不做求职诉求

- 状态：已接受
- 日期：2026-08-20
- 依赖：[ADR-0001](0001-site-positioning.md)、[ADR-0008](0008-job-intent-timing.md)、[ADR-0010](0010-ai-assisted-writing.md)

## 背景

当前站点上完全没有"人"——没有照片、没有工作之外的任何信息、没有一句非履历性质的自我表达。
在 ADR-0001 的定位下这不算错（站点是证据库），但走到极端就成了一份冷的技术档案。
课程里 Dependable Strengths 练习产出的那类东西（个人特质、故事）在现有结构中无处安放。

曾考虑让 About 页承载 cover letter 的可复用部分。**此路已否决**：
cover letter 会针对重点监控的岗位专门书写，是 per-job 的一次性产物，
与站点没有复用关系；硬把它塞进 About，还会与 ADR-0008（2027 前不写求职诉求）相撞。

## 决策

**建 `/about` 独立子页，只承载履历之外的个人面向——兴趣、爱好、工作之外在做的事。
不承载 cover letter 的任何内容，不承载求职诉求。**

### 页面职责

**写**：兴趣与爱好、工作之外持续在做的事、日常里一些具体而无害的细节、
可选的一小段"我为什么被这类问题吸引"（动机，不是诉求）。

**不写**：目标岗位、地域、工作许可（ADR-0008）；项目成就与技能的复述
（那是首页和 wiki 的事）；求职意愿的任何表达；观点性强或有争议的立场。

### 期望值设定：这是加分项，不是承重墙

这一页的正确目标是"**万一被读到，能为个人形象加分**"，不是"说服谁"。
它的收益与风险高度不对称：

- 上行有限——没有人会因为一页兴趣爱好而决定录用你；
- 下行不小——一句不合适的话、一段假模假样的抒情，会反过来污染整站的可信度。

因此优化方向是**压低负面信号的概率**，而不是把这页写得多有冲击力。
"不疼不痒"在这里是有意为之的设计目标，不是敷衍。

### 位置：独立子页，不放首页

首页保持为扫视优化的证据流。About 走导航栏 + Contact 附近一个小入口，做成 opt-in。

## 理由

- **子页正好命中受众。** 会点进 About 的，是**已经对你产生兴趣**的人——
  他们在确认"这人是不是个能一起工作的人"。这批人愿意花时间，所以不存在
  "藏太深没人看"的损失；反过来，把它铺在首页，会让为扫视优化的主线被一段软内容打断，
  且容易显得像凑数的填充物。
- **和 ADR-0008 天然不冲突。** 只要这页不谈"我要什么岗位"，
  就不会踩到工作许可与时间线未定的雷。动机和诉求是两回事。
- **具体细节比形容词有效得多。** 一句"我烤面包，最近在跟酸种较劲"比一整段
  "我热爱生活、充满好奇心"要真实一个数量级，而且后者恰恰是 AI 最爱写的句式。
- 这页也顺带补上了课程 Dependable Strengths 那部分的落点——
  不用把它写成成就清单，藏在具体的日常细节里反而更可信。

## 约束

1. **[ADR-0010](0010-ai-assisted-writing.md) 在这一页加倍适用。**
   这是全站最容易被识别为 AI 生成的一页（第一人称 + 兴趣叙述），
   同时又是**真实性即全部价值**的一页——它唯一的功能就是"像个人"。
   一旦读起来像 AI 写的，这页不但无效，还是负资产。
   建议直接手写，不要走"AI 起草再改"的流程。
2. **不写观点性内容**：政治、宗教、有争议的社会立场一律不进。
   下行风险远大于上行收益，与本页"加分项"的定位不符。
3. **不写空泛热情**：`passionate about technology` / `love solving problems` 这类
   零信息量的句子一律删除。写不出具体的，就不写这一条。
4. **不复述成就**。想到某个项目成果时，链到对应项目页，不在此处重讲。
5. **篇幅上限约 400 字**（中英文各自计）。这页越长，风险越大、收益越平——
   它不需要写满。
6. 页面维护频率低，内容应尽量选择**不会很快过期**的东西；
   写"最近在读某本书"这类内容要接受它会变旧，或干脆不写具体到月份的表述。

## 后果

- 首页依然没有"人"，人味完全依赖访客主动点进 About。这是接受的取舍：
  首页的职责是证据密度，不是亲和力。
- 多一个静态路由 `app/about/page.tsx`，静态导出无额外成本。
- 这页由于"低风险低收益"的定位，**优先级排在所有实质性改造之后**，
  不应挤占 Hero 文案、项目卡片等主线工作的时间。

## 未决

- **是否放照片。** 北美简历不放照片是惯例，但个人网站 About 页放照片是常态，
  且有助于"像个人"这个唯一目标。倾向于放，但需本人决定；
  若放，应是自然的工作/生活照，不是正装证件照。
