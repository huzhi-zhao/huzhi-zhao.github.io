# ADR-0006 Writing 板块的形态与上线时机

- 状态：已接受
- 日期：2026-08-20
- 依赖：[ADR-0005](0005-content-tiers-and-hosting.md)

## 背景

是否要为文章单开一个顶级板块，曾有分歧。

反对理由：眼下能拿出的成品文章接近零，为两三张卡片开一个顶级板块，
视觉上会空；而"Writing"栏目空着的负面信号比没有这个栏目更强。

支持理由（采纳）：这个站是为 1–2 年后设计的，不是为当下。2026 年底 UOIP 会产出一篇
有深度的 paper，加上偏工程的几篇（管道内/外数据质量审计、BQ 循环验证等），
一年内到 5–6 篇是合理预期。而且按 ADR-0005，L3 内容本来就**不属于任何单个项目**，
硬塞进项目卡片下面是错配。

另有一条外部信号支持这个板块：本地 JD 中多次出现 "strong technical writing skills" 与
"maintaining documentation of data definitions, report logic, and dashboard structures to
support long-term data governance"。文章不是锦上添花，是**岗位明文要求的能力样本**。

## 决策

1. **Writing 作为顶级板块存在**，位置在 Experience 之后、Contact 之前（见 ADR-0002）。
2. **布局采用「一篇 featured 大卡 + 其余列表行」，不用三列卡片网格。**
3. **上线时机卡在首篇 paper 完成时**（预计 2026-12），此前该板块不渲染。
4. 选题上，偏数据治理/质量的文章优先级**不低于**性能调优类。

## 理由

- 三列网格在数量少时会露馅：2 篇文章排 3 列格子，视觉上就是缺了一块。
  featured + 列表这个结构从 2 篇到 20 篇都成立，且天然有主次。
- 首篇 paper 是这个板块的立身之本。有它常驻 featured 位，
  上线时即使只有 1 篇 paper + 2 篇短文也不难看。
- 数据治理类选题直接命中本地保险 / 金融 / 薪酬雇主的关注点，
  这类雇主对治理的敏感度高于对纯性能调优的兴趣。看着"水"的选题，实际对口度可能更高。

## 约束

1. **板块在没有 featured 文章时不渲染**，不允许上占位内容、"coming soon" 或计划中的标题。
2. 列表行只显示标题 + 一句话 + 日期 + 阅读时长，不显示摘要段落。
3. 文章正文托管在知识库（ADR-0005），站点内不实现正文页。
4. featured 位同时只有一篇。想突出第二篇，说明该换掉第一篇了。

## 后果

- 板块上线时间取决于写作进度，属于计划外风险：若 paper 延期，板块跟着延期。
  这是有意接受的——空板块的代价更大。
